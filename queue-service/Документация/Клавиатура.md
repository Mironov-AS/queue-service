# Увеличение клавиатуры
Цель: увеличить ширину буквенно-цифровых кнопок на 20%, не затрагивая production.
Проект: /home/user/queue-service, React + Vite + Tailwind.
Правка: 36 → 43.2 px; высота и обработчики прежние. На узких экранах ширина ограничена доступным пространством для 11 клавиш.
Команды frontend: npm run dev, npm run build из client. Дополнительные env не нужны.
Production не обновлять до визуального согласования. Backend, данные, Docker и зависимости не меняются.
Проверка клавиатуры: отдельный dev-only стенд, без подключения к production API и без оформления реальных талонов.
Статус: локальные проверки в процессе. Безостановочный deployment пока не проверен; полный redeploy может перезапустить backend.

## Результаты
- Ширина основных клавиш 43.2 px, адаптивный max-width; высота 56 px без изменений.
- 3 component-теста прошли: размеры, ввод/удаление/пробел/RU-EN/подтверждение, отсутствие клавиатуры без полей.
- Тесты запускаются установленным Vitest из соседнего /home/user/client, tests/vitest.local.config.mjs специально локальный, production dependencies не изменены.
- Production frontend build успешно завершён; тестовый HTML не входит в dist.
- Изолированный dev-preview на порту 5175, корень и /terminal открывают стенд клавиатуры. HTTP 200 проверен.
- Визуальная проверка заблокирована: promto_preview дважды вернул HTTP 401 Authentication required. Screenshot не получен, готовность интерфейса не подтверждена.
- Production и реальные данные не затронуты; публикация не выполнялась.

## Уточнение: квадратные клавиши
По новому запросу ширина буквенных и цифровых клавиш установлена 56 px при прежней высоте 56 px. Предыдущий адаптивный max-width удалён: клавиши не сжимаются. Содержимое клавиатуры имеет min-width 692 px (11 × 56 + 10 × 6 + 16 padding), внешний контейнер допускает горизонтальную прокрутку на узких экранах. Пробел и служебные кнопки сохраняют прежнюю форму.
После правки: 3 теста прошли, build прошёл, /keyboard-preview.html отвечает HTTP 200. Screenshot снова заблокирован HTTP 401. Production не изменён.

## Уточнение: двойная ширина
Основные клавиши увеличены с 56 до 112 px, высота прежняя 56 px. Контейнер 1308 px = 11 × 112 + 10 × 6 + 16 padding. На более узких экранах горизонтальная прокрутка сохраняется. Служебные клавиши без изменений. После правки все 3 теста и build прошли, HTTP /keyboard-preview.html = 200. Screenshot недоступен (401). Production не обновлён.
